1-1. 진행 개요

  • 게임: 파이어 엠블렘 만자천홍 (Fire Emblem: Fortune's Weave, Switch 2) ✅
  • 목표: 하드 / 클래식에서 사망자 없이 네 로드의 1부를 차례로 끝낸다. 앞 루트가 연 병종·축복·가호·지원을 뒤 루트가 이어받는다. 레다·디트리히 2부를 직접 하고, 세오도라 2부는 스킵(또는 직접)으로 처리한 뒤, 축복이 다 쌓인 네 번째 루트로 카이 1부·2부를 하고 3부 최종전까지 간다
  • 구조: 서장 → 1부 대검투제편(루트당 12장, 루트는 서로 다른 세계선) → 2부 전쟁편(로드별 6장, 네 로드 공통 맵) → 3부 구세편(통합 6구간) ✅
  • 난이도 프로필: 세오도라 1부 = 중(11장 급상승 🔵) → 레다 1부 = 중(9~11장 강적전, 가호 이월로 완화 🔵) → 디트리히 1부 = 초~중(축복 2단계 + 가호 이월, 경험치 분배만 관리 🔵 🟡) → 2부 = 높음(4·5장 고비 🔵 🟡) → 카이 1부 = 중(축복 3단계지만 맵이 좁고 턴이 빠듯하다, 발로르 섬 도주 구간 🟡) → 3부 = 높음(최종 보스 마법 강함 🟡)
  • 패치: Ver 1.1.0(10/15)의 변경점은 확장 패스 대응과 타이틀 화면 '추가 콘텐츠' 링크뿐이다. 밸런스 조정·버그 수정은 없다 → 이 계획의 하드 수치·규칙은 그대로다 ✅. 루나틱이나 새 난이도도 없다 🔵.
  • DLC(확장 패스 1탄, 10/15): 시작품 무기 4종을 1부 루트마다 1개씩, 각 루트 1부 4장 이후 다그시온 안내판 서브퀘스트로 받는다 ✅. 무기 성능 수치는 공개된 것이 없다 → 받으면 바로 비교하고, 계획의 전제로 삼지 않는다.

  6. 세오도라를 첫 루트로 두는 것은 "카이나 세오도라가 첫 루트로 가장 무난하다"는 출처 간 유일한 공통점과 맞는다 🔵. 디트리히를 축복 EXP 버프 뒤에 두는 배치는 game8.jp의 효율 논리와 같다 🔵.

왜 카이를 네 번째(마지막 1부)에 두는가 (개정 3)

  3. 다른 로드 클리어가 조건인 서브퀘스트가 처음부터 열린다(「그 이름은 다·미나」 등) 🟡.
  4. 경험치 축복이 최대라 1부 안에 Lv45 전차병의 길 구간까지 갈 수 있다는 보고 🟡. 대신 초반에는 레벨이 친밀도·전직보다 앞서지 않게 관리한다(7절, 쟁점 48).
